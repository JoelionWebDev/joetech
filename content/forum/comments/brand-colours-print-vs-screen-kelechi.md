Screens use RGB and printers use CMYK — the same green will never match exactly unless you give both values. Your guideline needs the hex for screen, the CMYK values for print, and a Pantone reference if the client can afford it. Always print one test copy before a big run and show it to the client. And warn the client up front that print is always slightly darker — then it is expected, not a surprise.
