Buy the .ng and use it as the main domain — Google treats it as a local signal, which actually helps for Lagos searches. Customers here are used to .ng now, and it shows the business is Nigerian. If the budget allows, buy the .com too and redirect it, so nobody else takes it and nobody types the wrong one. But build everything on one domain only — never run the same site on both.
