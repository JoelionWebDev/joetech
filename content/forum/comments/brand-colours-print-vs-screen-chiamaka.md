It helps to explain it to the client this way: a screen glows, paper absorbs light, so the same green will always look brighter on a phone. Show them a printed proof next to the screen version before the big run, and put a "print version" of each colour in the brand guide so the printer never has to guess. That one page in the guide has saved me from this exact argument twice.
